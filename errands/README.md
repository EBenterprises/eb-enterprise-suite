# ERRANDS®

ERRANDS® is an errands, coordination, dispatch, runner, location,
tracking, communication, payment and operations platform.

Core lifecycle:

REQUEST
→ VALIDATE
→ MATCH
→ DISPATCH
→ ASSIGN
→ COORDINATE
→ TRACK
→ ARRIVE
→ HANDOFF
→ COMPLETE

Location types include:

- address
- business
- landmark
- entrance
- meeting point
- coordinates
- shared location
- live location
- custom instructions
