# Titan Automation Suite & Auto-Sync
Modular architecture combining high-speed port scanning, browser tab management, and automated GitHub synchronization for every paste and update.

## Usage
1. Configure your remote repository:
   `git remote add origin <YOUR_GITHUB_REPOSITORY_URL>`
   `git branch -M main`
2. Run the automation suite:
   `npm start`
3. Automatically commit and push all updates/pastes to GitHub:
   `npm run sync`
